A deployment can finish without errors while the application still fails for users.

Before calling a release successful, check three things:

• Is the new version working?
• Can it save and read data?
• Can you return to the previous version if something breaks?

Our new guide shows how to build these checks into AWS Lambda releases with GitHub Actions. It includes Python code, a simple diagram and tests you can run on your computer.
