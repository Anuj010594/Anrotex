USING THE NODE.JS WORKFLOW
Download: https://www.anrotex.com/downloads/node-ci.yml
Setup: https://www.anrotex.com/blog/cicd-best-practices#github-actions

The workflow builds and tests a Node.js 24 project. It expects a committed
package-lock.json, npm scripts named lint, test:ci and build, and output in
dist/. Review these settings for your application before saving it as
.github/workflows/node-ci.yml. It does not deploy to production. Configure
deployment checks and access separately, then verify a failing test blocks
release before relying on the workflow.
