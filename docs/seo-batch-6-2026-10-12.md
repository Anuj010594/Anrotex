## Tracking behavior

The existing helper now sends approved event fields to Vercel and, after consent and configuration, GA4. No additional package is required.

| Existing action | GA4 event | Meaning |
| --- | --- | --- |
| Committed page/route | `page_view` | Current page and title, with a previous-page referrer |
| Tracked CTA | `cta_click` | A consultation or other tracked CTA was clicked |
| Service link | `service_click` | A tracked specialist-service link was clicked |
| Guide link | `article_click` | A tracked guide link was clicked |
| Case-study link | `case_study_click` | A tracked case-study link was clicked |
| First form interaction | `form_start` | The existing form-start hook fired |
| Successful enquiry | `generate_lead` | `/api/send` returned an OK response with `success: true` |
| Failed enquiry | `form_error` | The existing form submission handler encountered an error |

`generate_lead` measures a received enquiry, not a qualified opportunity, booking or sale. Mailbox/CRM reconciliation is still needed to assess genuine leads and spam. Page visits and CTA clicks are not counted as leads.

Google's tag is not loaded before a visitor allows analytics cookies. Visitors can decline, change their choice in the footer, or withdraw consent. Withdrawal disables the GA4 tag, updates its consent state, and removes its standard first-party cookies. Choices persist when browser storage is available and changes synchronize across open tabs. Storage failures do not prevent the current choice from taking effect.

Advertising consent stays denied; Google signals and advertising personalization are disabled in the tag configuration. Only approved placement, destination, page and service-choice fields are forwarded. Names, email addresses, company names, messages, arbitrary fields and arbitrary URL parameters are excluded. External initial referrers retain only the origin. UTMs and `focus` are accepted only as short letters/numbers/dots/underscores/tildes/hyphens; campaign links should use those characters and must never contain personal information.

Vercel's existing cookie-free measurement remains available independently of the Google Analytics cookie choice. Its page URLs and Speed Insights URLs use the same query allowlist. GA4 totals therefore represent consenting visits and will not match Vercel or Search Console exactly.

### Excluding our own visits

Development builds, localhost, and Vercel preview hostnames are excluded from both providers. On production, open `https://www.anrotex.com/?analytics=off` once in each browser used for staff work or QA. This persists an exclusion in that browser. `?analytics=on` removes it. The control parameter itself is never sent in page URLs.

This is a browser-specific exclusion, not an automatic identification of every employee or tester. Clearing site storage or using another browser requires setting it again. If storage is unavailable the exclusion lasts only for the current page session. No historic analytics data is removed.
