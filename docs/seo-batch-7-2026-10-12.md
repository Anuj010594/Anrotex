# Batch 7 — Guide navigation, enquiry context and distribution

Prepared on `main`, 12 October 2026, following production commit `72c7120`.

## Site changes

The shared article layout previously placed its contents list below the complete article on mobile. The AWS, CI/CD and Kubernetes guides now have a compact native “Jump to a section” control near the top, with keyboard operation and a visible link to the relevant service or consultation. Desktop retains the existing sticky contents list. The underlying articles, titles, publication dates, canonical URLs and sitemap are unchanged.

Article links to a specialist service now use the existing `service_click` event. Consultation links continue to use `cta_click`. Both placements identify their source without new events or dependencies.

The shared enquiry form now includes the selected service in `form_start` and `form_error`, using the same allowlist already applied to successful submissions. A start records the selection at first interaction; if the visitor chooses a service later, the start can legitimately be “Not specified” while the eventual submission names a service. Errors record the choice submitted on that attempt. No name, email, company or message is added to analytics. Consent and internal-browser exclusions are unchanged.

## GA4 exploration — partially saved, not ready for reporting

Property: `Anrotex website` (`558510601`).

[Anrotex — visits to enquiries](https://analytics.google.com/analytics/web/?authuser=1#/analysis/a411624868p558510601/edit/npnXSh4ESj6phkdAmvrgLA)

The exploration name, tab name `Service-link journey`, four event steps and imported dimensions persisted after a reload:

1. Site visit: `page_view`.
2. Service link clicked: `service_click`.
3. Enquiry started: `form_start`.
4. Enquiry received: `generate_lead`.

Steps are indirectly followed: other events can occur between them. This is a closed, user-based journey across the report period, not a same-session conversion rate. A service click is a tracked link interaction, not proof of a successfully loaded service page. Direct service/contact arrivals and enquiries that skip a service click are not completions of this specific four-step sequence.

Imported dimensions include Country, Session source, Session medium, Session campaign and Landing page + query string. The combined Session source/medium dimension was unavailable for selection in this funnel, so use its separate dimensions.

GA4 repeatedly returned “There was an error loading data for this component”, “Internal error. Please try again later” and an exploration save error. After reload, the additional source breakdown and target-country/QA filters had not persisted; the saved report retained Device category and no filters. Do not use this report for target-market conclusions yet. No conversion results were inferred from an empty chart. Realtime event ingestion was verified in batch 6; it is separate from this exploration error.

- Breakdown: Session source. Use Session medium or Session campaign when reviewing distribution. For content entry points, change the breakdown to Landing page + query string.
