# SEO batch 5 — Loading performance and enquiry tracking

Prepared 8 October 2026 on `main`, following production commit `97b23d3`.

## Changes

- Split the 15 page components into separate JavaScript downloads. Prerendering waits for each route to finish, preserving the full initial HTML, metadata, structured data, FAQs, and article content.
- Preload the current page and its shared imports using Vite’s build manifest. Other pages load when visited. React transitions retain the current page while the next route loads; section scrolling runs after the new content commits.
- Serve the existing Urbanist variable font from Anrotex, with a preload for its Latin subset, font-display swap, and the original SIL Open Font License. Removed the Google Fonts stylesheet and cross-origin font connections.
- Reused the existing analytics helper for six service cards, the services introduction enquiry link, four footer service links, and the footer consultation link. Events contain placement and destination, with no form contents or personal details.
- No new dependencies or editorial labels were added to public pages.
