# Batch 10 — Enquiry recovery, verified profile and first guide distribution

Prepared on `main`, 12 October 2026, after production commit `5371518`.

## Website changes

- Added a React error boundary around page rendering. A rejected page import now shows a plain-language recovery screen with a native **Try again** link and `sales@anrotex.com` email alternative. The heading receives focus, and the page title identifies the recovery state.
- Retry performs a user-initiated document navigation to the full requested pathname, query and fragment. This fetches the current deployment's HTML and assets and preserves enquiry service choices. There is no automatic reload or retry loop.
- A separate boundary contains optional Vercel analytics and Speed Insights failures. Those failures no longer unmount the page or erase a loaded enquiry form. No form details are added to browser storage or analytics.
- Added **Anuj Dhadge** and his verified [LinkedIn profile](https://www.linkedin.com/in/anuj-dhadge-929963408/) to the existing team card. His name, profile URL and Anrotex co-founder affiliation were visible in the signed-in LinkedIn UI on 12 October. Existing engineering descriptions and roles are unchanged; no new experience, qualifications or client claims were added.

The recovery boundary requires the application's initial JavaScript to load. It does not solve a complete network outage or preserve drafts across an intentional page departure or manual refresh. It protects page-rendering failures and isolates optional telemetry failures; it is not an enquiry draft-storage feature.
